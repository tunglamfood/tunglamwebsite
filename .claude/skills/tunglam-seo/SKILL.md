# Tung Lam SEO playbook

The old site (tunglamfood.com, built by NEWPAGES) relies on keyword-stuffed templated titles, identical boilerplate
descriptions, 90+ thin `/tag/` pages and an invalid Product `Offer`. We beat it with unique content, clean URLs,
three languages and complete structured data. Keep it that way.

## Architecture facts
- i18n: English at root (`/products`), Malay at `/ms/...`, Chinese at `/zh/...`. `src/proxy.ts` rewrites unprefixed
  paths to `/en/...` and 308-redirects any explicit `/en/...` to the unprefixed URL (no duplicates).
- hreflang: `en-MY`, `ms-MY`, `zh-Hans-MY` + `x-default` — generated by `languageAlternates()` in `src/lib/seo.ts`.
- Rendering: static generation + ISR (`export const revalidate = 3600`, fetch tag `content`). Unknown slugs must call
  `notFound()` (real 404 status — never a soft 404).
- Legacy URLs: `src/data/legacy-redirects.json` (generated by `scripts/seed.mjs`) → `next.config.ts` permanent redirects.

## Checklist for every new page
1. Lives under `src/app/[lang]/...`, validates `hasLocale(lang)` and calls `notFound()` otherwise.
2. `generateMetadata` returns `pageMetadata({ locale, path, title, description, ... })` — `path` is locale-agnostic.
   - Title ≤ 60 chars, unique, primary keyword first, no stuffing. Description 140–160 chars, unique, with a reason to click.
   - Add the strings to all three dictionaries in `src/i18n/dictionaries/` (TypeScript enforces parity).
3. Exactly one `<h1>`; logical `h2`/`h3` order.
4. Breadcrumbs via `<Breadcrumbs>` (emits BreadcrumbList JSON-LD automatically).
5. Structured data via `<JsonLd>` using builders in `src/lib/seo.ts` (Product, Recipe, FAQPage, ItemList, Brand).
   Only mark up content that is visible on the page. Don't add `Offer` without a real price.
6. Add the route to `STATIC_PAGES` in `src/app/sitemap.ts` (dynamic content is added automatically).
7. Images: `next/image` with meaningful `alt` (product name), `sizes`, `priority` only for the LCP image.
8. Internal links: link new pages from nav/footer or related sections so they're crawlable.
9. If a URL changes, add a permanent redirect — never break an indexed URL.

## Verify
`npm run build && npm start`, then `npm run qa` (checks status codes, redirects, hreflang, JSON-LD, mobile overflow).
Validate structured data at https://search.google.com/test/rich-results and https://validator.schema.org.

## Off-site (tell the user; not code)
Google Search Console + Bing Webmaster for tunglamfood.my (submit `/sitemap.xml`), Google Business Profile pointing to
tunglamfood.my, and when ready 301 the whole tunglamfood.com domain to tunglamfood.my to transfer its authority.
